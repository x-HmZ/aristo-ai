# Aristo AI — Technical Summary

## 1. Project Purpose
Aristo AI is a knowledge-graph-driven, mastery-based AI tutoring platform for middle-school students (grades 6–8). A 3D avatar teacher (rendered with React Three Fiber) delivers structured 5-phase lessons (Activate → Explain → Demonstrate → Challenge → Connect) generated by Claude. Lessons adapt to a behaviorally-inferred learner profile, per-concept mastery is tracked with Bayesian Knowledge Tracing, and long-term retention is enforced via a spaced-repetition queue. Physical/tangible topics trigger on-the-fly 3D model generation that appears in the scene next to the avatar.

## 2. Architecture
- **Framework:** Next.js 15 (App Router) with a deliberate Pages Router exception for [pages/learn.tsx](pages/learn.tsx) — App Router's `(app-pages-browser)` webpack layer aliases React in a way that crashes `react-reconciler@0.27.0` (R3F's dependency), so the 3D `/learn` page is isolated in Pages Router with `getServerSideProps` for SSR auth and `next/dynamic({ssr:false})` for the client shell.
- **Agent layer** ([src/lib/agents/](src/lib/agents/)): four specialized agents — TeachingAgent (5-phase lesson), AssessmentAgent (quiz gen + answer eval), CurriculumAgent (course builder via topological sort of the KG), ProfilerAgent (pure rule-based behavioral profiler — no LLM).
- **Structured-output everywhere:** every Anthropic call uses `tool_use` with strict JSONSchema input schemas ([teaching.ts:404](src/lib/agents/teaching.ts#L404), [assessment.ts:52](src/lib/agents/assessment.ts#L52)). No regex JSON parsing.
- **Knowledge Graph** ([src/lib/kg/graph.ts](src/lib/kg/graph.ts)): concepts + directed prerequisite edges; Kahn's algorithm for topological sort; recursive CTE view for transitive prerequisites.
- **RAG** ([src/lib/rag/](src/lib/rag/)): pgvector + OpenAI embeddings, HNSW index, top-k cosine retrieval injected into the TeachingAgent prompt.
- **Mastery + SRS** ([src/lib/mastery/update.ts](src/lib/mastery/update.ts)): Bayesian Knowledge Tracing per concept; simplified FSRS scheduler with difficulty-adjusted ease factor.
- **Lesson cache** ([migration 014](supabase/migrations/014_lesson_cache.sql)): generated lessons cached keyed by `(concept_id, profile_signature)` with admin moderation queue (`pending`/`approved`/`auto_approved`/`rejected`).
- **State:** Zustand store persisted to sessionStorage ([src/store/useAristoStore.ts](src/store/useAristoStore.ts)).
- **Approval gate:** middleware + page-level SSR + `requireApproved()` API-route guard ([src/lib/auth/approval.ts](src/lib/auth/approval.ts)) — defence-in-depth pre-paywall.
- **Adaptive visuals flag:** dual-emit lesson schema (legacy 5-phase blocks + new ordered `segments` array) gated on `NEXT_PUBLIC_ADAPTIVE_VISUALS` so it can be rolled back instantly.

## 3. AI/ML Components
- **Claude Sonnet 4.6** (`claude-sonnet-4-6`) — TeachingAgent (5-phase lessons), AssessmentAgent.generateLessonQuiz, CurriculumAgent.
- **Claude Haiku 4.5** (`claude-haiku-4-5-20251001`) — `explainMore`, `generateReviewQuestion`, `evaluateShortAnswer`, free-mode chat companion.
- **Centralized model IDs** ([src/lib/agents/models.ts](src/lib/agents/models.ts)) — no hardcoded model strings elsewhere.
- **Prompt engineering:** dual system prompts (legacy + adaptive), ephemeral cache_control on system blocks for prompt caching, few-shot example embedded for the adaptive segment format, profile-shaped templating that injects expertise/depth/pace/example-preference into every user message.
- **Embeddings:** OpenAI `text-embedding-3-small`, 1536 dimensions, ~450-token chunks with 200-char overlap ([src/lib/rag/embed.ts](src/lib/rag/embed.ts)).
- **Vector retrieval:** pgvector cosine similarity via `match_reference_chunks()` RPC, top-4 chunks filtered at similarity > 0.3 ([src/lib/rag/retrieve.ts](src/lib/rag/retrieve.ts)).
- **Evaluation logic:** local deterministic eval for MCQ/true-false/fill-blank/ordering/matching ([assessment.ts:410](src/lib/agents/assessment.ts#L410)); Haiku tool-use eval with partial credit + misconception detection for short-answer and code-debugging.
- **Behavioral profiler:** rule-based conservative ordinal-shift updater driven by session signals (explain-more clicks, avg quiz response time, accuracy) + per-Bloom-level accuracy ([profiler.ts](src/lib/agents/profiler.ts)).
- **BKT:** Bayesian update with difficulty-conditioned `P(correct|mastered)`, `P(slip)`, and lucky-guess probability ([update.ts:18](src/lib/mastery/update.ts#L18)).
- **SRS:** simplified FSRS with expanding intervals (`1d → 3d → ×ease_factor`), 70/30 review-vs-lesson blend escalating to 50/50 when ≥10 cards overdue ([learn/next/route.ts](src/app/api/learn/next/route.ts)).

## 4. APIs and Services
- **Anthropic API** — wrapped client with per-call usage logging ([src/lib/llm/anthropic.ts](src/lib/llm/anthropic.ts)) writing to `usage_events` for cost attribution.
- **OpenAI API** — embeddings (RAG) + Whisper STT (`whisper-1`, verbose_json) at [/api/whisper/route.js](src/app/api/whisper/route.js).
- **fal.ai** (`@fal-ai/client`) — three models:
  - `fal-ai/nano-banana-pro` — Gemini-3-Pro powered educational infographic generator (per-segment and topic-level visuals).
  - `fal-ai/flux/schnell` — clean isolated object image for 3D source.
  - `fal-ai/triposr` — image→GLB textured mesh.
- **ElevenLabs TTS** — `eleven_turbo_v2_5` proxied at [/api/tts/route.ts](src/app/api/tts/route.ts), 5 voice IDs mapped to avatar personas.
- **Resend** — admin "new signup" email notifications (idempotent via `admin_notified_at`).
- **Google Generative AI SDK** (`@google/generative-ai`) — dependency present.
- **Supabase** — auth, Postgres with RLS, pgvector RPC, service-role client for admin/server paths.
- **Avaturn SDK** — user-generated custom avatar creation.

## 5. Data Pipeline
- **RAG ingest** ([/api/kg/ingest/route.ts](src/app/api/kg/ingest/route.ts)): admin-only POST → `chunkText()` (1800-char chunks, 200-char overlap) → batched-5 OpenAI embeds → insert into `reference_chunks` with domain tag.
- **Retrieval:** lesson route builds query `"{name}: {description}. {objectives}"` → embed → pgvector cosine search → filter similarity > 0.3 → injected as `<reference_material>` block.
- **Behavioral signal pipeline:** client buffers signals in Zustand → `useSessionFlush` hook flushes on `beforeunload` (keepalive) → `/api/profile/session` runs ProfilerAgent → upserts `learner_profiles`.
- **Lesson cache pipeline:** generation result → moderation decision → upsert into `cached_lessons` keyed by `(concept_id, profile_signature)` → atomic `increment_cached_lesson_usage` RPC on cache hit.
- **In-memory warm cache for fal.ai** ([imagegen/banana.ts](src/lib/imagegen/banana.ts)): three SHA-256-keyed Maps (NB Pro, FLUX, TripoSR) with 12h TTL and LRU eviction, leveraging Vercel Fluid Compute instance reuse to cut TripoSR cost (the most expensive call at $0.07/gen).
- **Usage/cost logging:** every Anthropic/OpenAI/fal.ai call writes to `usage_events` with per-feature tags, token counts, and micros-precision USD cost ([pricing.ts](src/lib/llm/pricing.ts)).

## 6. Database and Storage
**Supabase Postgres**, 14 migrations (`001` → `015`, no `007`). Notable tables:
- `concepts` + `concept_prerequisites` (knowledge graph) + recursive view `concept_all_prerequisites`
- `profiles` (extends `auth.users` with `approval_status`, `is_admin`)
- `learner_profiles` (dynamic, behaviorally inferred)
- `user_concept_mastery` (BKT score + 6 SRS columns)
- `user_course_progress`, `user_misconceptions` (with `increment_misconception()` RPC), `session_logs`, `quiz_attempts`
- `courses` (generated curriculum structure as JSONB)
- `reference_chunks` with `vector(1536)` column + HNSW index (`m=16, ef_construction=64`)
- `cached_lessons` with moderation status + atomic usage counter
- `usage_events` + `audit_log`

Row Level Security policies on every table; ownership-scoped read/write for learners; `service_role` for admin paths.

## 8. Notable Technical Achievements
- **App Router / Pages Router hybrid** to work around an R3F + react-reconciler incompatibility with App Router's React aliasing — documented and intentional.
- **Dual-emit lesson schema** so the new adaptive-visuals system ships behind a flag without breaking the legacy phase-block consumers.
- **Profile-aware lesson cache** keyed by hashed profile signature — same concept regenerated only when the learner's expertise/depth/pace/example-preference would actually change the lesson.
- **Three-tier image-gen cost optimization**: NB Pro (~$0.04) + FLUX Schnell ($0.003) + TripoSR ($0.07) all warm-cached at module scope, exploiting Fluid Compute instance reuse.
- **Defense-in-depth approval gate**: middleware redirect + Pages Router SSR check + per-route `requireApproved()` guard, after initial single-layer attempts hit @supabase/ssr cookie-parse failures in the Edge Runtime.
- **Local-first answer eval**: 5 of 8 question types evaluated deterministically client-/server-side without LLM round-trip; only short-answer and code-debugging pay for a Haiku call.
- **Per-call cost telemetry**: every LLM and fal.ai call attributed to a feature tag with micros-precision USD, surfaced on an admin cost dashboard with per-user/per-feature breakdowns.
- **Adaptive narration engine** ([useLessonPlayback.ts](src/hooks/useLessonPlayback.ts), [LessonPlayer.tsx](src/components/learn/LessonPlayer.tsx)): segment-driven state machine syncing TTS audio, viseme-driven mouth morphs, gestures, and per-segment image generation.
- **Topological-sort course generation**: Kahn's algorithm over the KG, mastery-filtered, then Sonnet groups concepts into modules/lessons.
- **70/30 SRS blending** with adaptive escalation to 50/50 when learners fall behind.
